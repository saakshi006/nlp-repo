# NLP Knowledge Artifact Repository – Week 1

> **Tagline:** *"Understanding Natural Language Processing from Text to Intelligence."*

This repository is a complete, modern, responsive educational documentation website built to explain and compare the fundamental concepts of Natural Language Processing (NLP) covered in Week 1. 

The website has been styled with a warm **Brown & Beige** academic theme, drawing design inspiration from Notion, GitHub Docs, Apple Books, and Medium. It is built using only standard **HTML5, CSS3, and Vanilla JavaScript** without any external frameworks.

## 🌟 Key Features

1. **Academic Brown & Beige Palette:** High-contrast, accessibility-friendly theme utilizing academic tones with beautiful Playfair Display headings and Poppins body text.
2. **Dynamic Dark Mode:** Features a cached toggle that synchronizes and stores dark theme configurations under standard `localStorage`.
3. **Interactive Concept Cards (Section A):** A catalog of **21 core NLP concepts** categorized under *Text Preprocessing, Feature Engineering, Language Representations,* and *Language Models*. Each card includes definitions, step-by-step algorithms, examples, and key research notes.
4. **Responsive Comparison Matrices (Section B):** Tabular comparative analyses (covering metrics like computational complexity, memory usage, and advantages) for key concept pairs (e.g. Stemming vs Lemmatization, Word2Vec vs FastText).
5. **Interactive SVG Pipelines (Section C):** Custom-built vector workflow diagrams featuring dynamic hover states and animated connector pathways.
6. **Real-World Use Cases (Section D):** Conceptual case reviews showing how fundamental Week 1 NLP tools translate to search engines, translation software, sentiment tools, chatbots, and text summarizers.
7. **Research & Industry Insights (Section E):** An interactive vertical timeline profiling Transformer advancements, Google Search updates, ChatGPT, spaCy, and Retrieval-Augmented Generation (RAG).
8. **Real-time Search Filter:** Instantly query terms, descriptions, or badges across the 21 concept cards as you type.
9. **Animated Statistics:** Auto-increments numeric counters when they enter the viewport using Intersection Observers.
10. **Print-to-PDF Engine:** Standardized print layouts that hide navigational menus and expand collapsible cards to export clean, formatted report portfolios.

## 🚀 Running the Project

Since this project is built entirely on pure client-side web technologies, running it is simple:

1. **Direct Browser Execution:**
   - Double-click or open [index.html](file:///c:/Users/lab605/Desktop/nlp/index.html) in any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox).
   
2. **VS Code Live Server (Optional):**
   - If using VS Code, right-click `index.html` and click **"Open with Live Server"** to view it with live reload capabilities.

3. **PDF Export:**
   - Click the **"Download PDF"** button in the header (or press `Ctrl+P`/`Cmd+P`) to export the repository as a structured, academic document.
